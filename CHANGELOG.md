# Changelog

## 2026-10-05 (later)
- **OpenCode 1.18.34 migration shipped: patcher ports + update tooling**: all four desktop patchers ported to the new bundle (desktop-ui v4.5 - scoped anchors, `ModelSelectorPopoverV2View` MenuV2 picker found via live-DOM canary after three wrong static targets, 40rem menu + inner scroll, badge chips in ModelList AND menu rows, Plugins menu re-wired; session-menu v6.2 - flat MenuV2 trim items in both title-menu variants, 120->210px; edit-candidates + image-capability re-anchored). **Keychain fix**: all patchers sign with the stable `OpenCode Local Notifier` identity - ad-hoc resigns broke the "OpenCode Safe Storage" ACL (repeat password prompt every run). **CSS staleness root-caused**: the `oc://` protocol caches same-named assets, so in-place stylesheet edits were invisible across restarts; patchCss now publishes `main-oc-<sha256[:10]>.css` + rewrites index.html. **New tools**: `oc-update-118` (manual updater: checkzip/apply/verify/rollback, sha512-verified, bundle preserved via rename, refuses while the app runs - the in-app "Restart now" silently fails on patched bundles), `oc-post-update` (runs all four patchers fail-fast), `oc-clear-cache` (regenerable renderer caches), `badge-toggle <ctx|img|cost>` (state.json + oc-ui re-patch in one call; Plugins menu gained Model-badge checkbox entries). Known gaps documented: Ollama models show no badge chips (provider reports no metadata); 2 of 3 unused model-picker containers stay patched harmlessly. `oc-ui` unchanged (verified identical).

## 2026-10-05
- **class-sweep: pattern contracts + full userscript class coverage; name collision resolved**: `contracts.json` gains declarative `mustContain` pattern contracts (fixed-string, grep-line-count semantics, `count` exact or `min` at-least) and `installedTwin` (installed userscript copy must match the project copy, drift = redeploy flag). Userscript checks extended: canary-proven quote scanner (the detector must catch a known-bad file before a clean result is trusted), marker traps (TODO/FIXME/XXX/HACK), duplicate top-level `var` detection (legal JS `node --check` passes; silent-wipe class), `@match` presence, version sync vs the project WORKLOG with note-skip when the newest entry carries no version. Motivated by web-smoother's project-local `tools/class-sweep.sh` sharing the hub tool's name: its 7 generic checks moved into the hub, its 6 project-specific invariants became `mustContain` data in its contracts.json, and the local script was retired - one sweep command, zero project-specific logic in the shared tool.

## 2026-10-01

Counter-drift check made convention-optional (skips instead of failing projects without the counters ledger). **Scope warning documented everywhere it belongs**: the userscript checks are structural - a real incident (a toggle whose CSS existed but was never registered, so the feature silently never ran) passes every structural check and is only catchable by executing the shipped bytes against a stubbed environment; the sweep now says so in its header, its pass output, and the README.
